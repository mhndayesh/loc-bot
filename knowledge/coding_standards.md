# Coding Standards & Best Practices

This document defines the **MANDATORY** coding standards for all code generated by the agent. Retrieval of this document implies you are writing code.

## Python Standards

### 1. Style & Formatting
- **PEP 8**: Follow PEP 8 strictly.
- **Line Length**: Limit lines to 100 characters where possible.
- **Imports**: Group imports: Standard Library > Third Party > Local.
  ```python
  import os
  import sys
  
  import requests
  
  import memory
  ```

### 2. Type Hinting
- **Always** use type hints for function arguments and return values.
  ```python
  def calculate_total(items: list[float], tax_rate: float = 0.05) -> float:
      """Calculate total with tax."""
      return sum(items) * (1 + tax_rate)
  ```

### 3. Error Handling
- **Never** use bare `except:`. Always catch specific exceptions.
- **Log** errors detailedly before returning/raising.
  ```python
  try:
      with open(path, "r") as f:
          return f.read()
  except FileNotFoundError:
      logger.error(f"File not found: {path}")
      return None
  except Exception as e:
      logger.error(f"Unexpected error reading {path}: {e}")
      raise
  ```

### 4. Path Handling
- **Always** use `os.path.join` or `pathlib.Path`. Never hardcode separators (e.g., `\\` or `/`).
- **Always** use absolute paths or resolve relative paths against `__file__`.

## JavaScript / Frontend Standards

### 1. Modern ES6+
- Use `const` and `let`. Never use `var`.
- Use arrow functions for callbacks.
- Use `async/await` instead of `.then()` chains.

### 2. Error Handling
- Wrap async calls in `try/catch`.
- Always provide visual feedback to the user on error (e.g., a toast or alert).

### 3. DOM Manipulation
- Minimize direct DOM manipulation; use the provided state management or framework if available.
- If using Vanilla JS, cache selectors.
  ```javascript
  const submitBtn = document.getElementById("submit");
  submitBtn.addEventListener("click", handleSubmit);
  ```

## Security Protocols

1.  **Input Validation**: Never trust user input. Sanitize all file paths and shell commands.
2.  **Secrets**: Never hardcode API keys. Use `os.getenv` or the `config.json` loader.
3.  **Traversals**: Always check if a resolved file path is within the allowed workspace.
